# Школьная библиотека

Информационная система учёта выдачи книг в школьной библиотеке (проект SA 11.2A / 11.2B).

**Проблема:** сейчас выдача книг записывается в бумажный журнал. Библиотекарь не видит быстро, у кого какая книга и кто просрочил возврат, поэтому книги теряются.

**Решение:** веб-приложение с базой данных, где выдача, возврат и просрочки видны сразу.

## Возможности

- Главный экран: статистика и кнопки для всех задач
- Выдать книгу: форма ввода с проверками (есть ли свободный экземпляр, не больше 3 книг, нет просрочек) и квитанция (форма вывода)
- Вернуть книгу и история возвратов
- Каталог книг с поиском и добавлением
- Список учеников
- Отчёт о просрочках с печатью
- SQL-консоль: настоящая SQLite в браузере (sql.js) для `CREATE TABLE`, `INSERT INTO`, `SELECT ... WHERE ... AND ... OR ...`

## База данных

| Таблица | Поля |
|---|---|
| Students | **student_id** (PK), first_name, last_name, class, phone |
| Books | **book_id** (PK), title, author, genre, year, copies |
| Loans | **loan_id** (PK), student_id (FK → Students), book_id (FK → Books), issue_date, due_date, return_date |

Связи: Students 1 — ∞ Loans, Books 1 — ∞ Loans.

SQL-скрипты лежат в папке [`sql/`](sql/).

## Запуск

Сборка не нужна: это статический сайт (`index.html`, `style.css`, `app.js`). Откройте `index.html` в браузере или задеплойте папку на Vercel.

Данные хранятся в браузере (localStorage), кнопка «Сбросить демо-данные» возвращает начальные записи.
